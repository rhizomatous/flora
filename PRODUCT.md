# Flora product context

## Register

product

## Users

Developers maintaining GitHub repositories who want to delegate coding work from a browser while retaining control of their infrastructure. The initial release serves one trusted administrator on one Linux host.

## Product Purpose

Describe a task, let an agent work asynchronously, return to a persistent conversation, review changes, and request a draft pull request. The authoritative requirements live in [specs/PRD.md](specs/PRD.md).

## Brand Personality

Friendly, quiet, capable. The flower mark and Flora character provide a small human touch in a focused developer tool. The initial shell uses restrained greyscale surfaces, system typography, and a dark default theme.

## Design Principles

- Make execution state and saved work understandable.
- Keep persistent conversations and review central to the workflow.
- Favor simple, familiar controls and honest descriptions of available features.
- Keep self-hosting and maintenance straightforward.

## Accessibility & Inclusion

Use semantic HTML, visible keyboard focus, sufficient contrast, and layouts that work on small screens. Respect reduced motion. Dark mode is the specified default; support light mode too.
